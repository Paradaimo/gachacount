# GachaCount

Приложение-компаньон для **Genshin Impact** и **Honkai: Star Rail**: pity-счётчики, текущие баннеры и полная история вылетов.

## Установка

1. Скачайте APK: [GachaCount-v0.1.9.apk](https://raw.githubusercontent.com/Paradaimo/gachacount/main/app/GachaCount-v0.1.9.apk)
2. Откройте файл на телефоне → разрешите «Установку из неизвестных источников» для вашего браузера/менеджера файлов.
3. Готово. Иконка «GachaCount».

> Если телефон ругается на неизвестный источник — это нормально, приложение распространяется напрямую.

## Как пользоваться

1. **Вход**: на главном экране нажмите на строку внизу («Не в системе…») → войдите в HoYoLAB в открывшемся окне (почта + пароль, как обычно). Либо вставьте cookie вручную («Вставить cookie» → `login_tma=...` + UID).
2. **Счётчики**: выберите игру (Genshin / Star Rail) → «Обновить счётчики». Приложение подтянет вашу историю вылетов и покажет pity по персонажам и оружию/конусам, статус 50/50 и последнего 5★.
3. **Баннеры**: список активных и ближайших баннеров (данные обновляются в этом репозитории, без переустановки приложения).
4. **История**: все 4★ и 5★ с баннером и датой + статистика.

## Приватность

- Cookie HoYoLAB хранится **только на вашем телефоне** (локально, не в облаке).
- Запросы идут только на официальные серверы HoYoverse (история вылетов) и на GitHub raw (данные баннеров). Никаких сторонних серверов.
- Приложение не содержит никаких ключей и токенов.

## Обновления

Когда выйдет новая версия — скачайте новый APK из [папки app](app) и установите поверх старого (подпись та же, данные сохранятся).

Данные баннеров обновляются автоматически при запуске приложения (файлы `data/*.json` в этом репозитории).
